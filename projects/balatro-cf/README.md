# Balatro-CF

状态：进行中 · Agent evaluation

## 当前认识

当前方向的工作假设是：一个 probe 不只是改一道题，而是对可恢复状态做一次受控干预。先构建 generator，再验证 probe family 的有效性，最后用 held-out systems 检验 compact evaluation 是否保留了长期行为信号。

## 技术路线

- 可恢复状态与分叉执行
- 受控干预与 probe 验证
- 待推进：紧凑题集与未见模型评测
