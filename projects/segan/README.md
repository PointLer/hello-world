# 重复定价与行为反馈

状态：在投 · SEGAN

## 当前认识

这条线把一次性需求响应改写为 repeated control：价格影响当天购买，也会通过 bounded-confidence willingness update 改变未来的参与状态。模型里保留 minimum daily-energy floor、shadow-price coupling，以及带因果信息结构的 factorized actor–critic。

## 技术路线

- 用能约束与影子价格
- 意愿反馈与重复定价
- 整理：结构化 actor–critic
